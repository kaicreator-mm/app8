# v0.4 — Public-only SE10/SE11 pre-evaluation preflight

Issue scope: [#149](https://github.com/kaicreator-mm/app8/issues/149) + [#150](https://github.com/kaicreator-mm/app8/issues/150), controller [#147](https://github.com/kaicreator-mm/app8/issues/147).

**This check never reads private semantic Gold or hidden truth. It cannot certify independent human authorship, unseen decisive fixtures, real execution, pass thresholds, Product Freeze or Release.** Its purpose is to find missing/mismatched **public** artifacts **before** costly evaluated prediction/execution.

## Read-only command

At the exact repository HEAD:

```bash
python scripts/v04_empirical_public_preflight.py --out /tmp/app8-v04-public-preflight.json
```

The initial result must honestly report:

```text
SE10=BLOCKED_PRE_EVALUATION
SE11=BLOCKED_PRE_EVALUATION
FORMAL_PRODUCT_RELEASE_QUALIFIED=NO
```

Use *only when the private independently curated materials really exist and their PUBLIC commitments have been generated by reviewed Stage B scripts*:

```bash
python scripts/v04_empirical_public_preflight.py \
  --se10-gold-public "<PUBLIC_SE10_GOLD_COMMITMENT>" \
  --se10-prediction-public "<PUBLIC_SE10_PREDICTION_COMMITMENT>" \
  --se11-target-manifest "<APPROVED_PUBLIC_SE11_TARGET_MANIFEST>" \
  --se11-hidden-public "<PUBLIC_SE11_HIDDEN_COMMITMENT>" \
  --out "<OUTSIDE_REPO>/v04-public-preflight.json"
```

It checks repository **exact Git blobs** for SE10 protocol/source pack/76-anchor allowlist/Stage C, SE11 amended protocol/Stage C; verifies strict JSON no duplicate keys and expected public shapes; checks SE10 Gold→prediction public SHA256 binding and frozen asset counts; checks SE11 target↔hidden public SHA256 binding, 4×20 / 8+4+4+4 class counts, no exposed truth field and mandatory applicability review references.

The command prints *only safe status codes and public Git blob identities*, not hidden labels, semantic Gold, HMAC seeds or actual private fixture contents. Output paths and secret private files should remain off-repo. Missing or invalid inputs yield `BLOCKED_PRE_EVALUATION` and CLI exit code 2; never substitute model-authored Gold or historical Stage A smoke for an evaluated run.

When all public metadata matches, the result is **`PUBLIC_METADATA_PRESENT_UNVERIFIED_INDEPENDENCE`**, NOT SE10 or SE11 PASS. An actual external independent review of the sealed materials plus separately pinned evaluator/config/execution/scoring and frozen thresholds is still needed. Do not label a synthetic test fixture a real public commitment.
