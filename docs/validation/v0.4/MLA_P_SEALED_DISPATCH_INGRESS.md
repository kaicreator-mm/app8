# v0.4 P trusted transport to app8 compiler (candidate path)

Refs #166 / #149. The existing trusted HTTPS dispatch can commit one prospective P request and preserve an opaque raw response in the private EvidenceStore. PR #191 introduced a source-bound converter for six typed P candidate cases that invokes the actual `app8.orchestration.freeze_hypotheses` product contract, but there was no common entrypoint from sealed bytes to that compiler.

`scripts/v04_mla_p_dispatch_ingress.dispatch_and_ingest_p` now connects the two **without adding a provider transport, changing protocol or expanding the 12-call budget**. It preflights source-context SHA256 before spending, invokes `dispatch_frozen_completion(role="P")` (including its per-call independent GitHub witness and budget guards), reopens only the response from the integrity-checked sealed store, decodes its single complete OpenAI completion, and passes the six source-pinned P candidate rows into the real app8 hypothesis compiler. Any malformed response or contract mismatch refuses candidate output. Neither a test transport nor raw response text is accepted as a privileged call argument.

The output is exclusively `HOST_P_RESPONSE_COMPILED_MODEL_PROPOSAL_ONLY` and hash/event pointers, **not provider-side attestation, source truth, verified behavior, Capability promotion, an old SE10/SE11 result or Release**. The transport's own returned event MAC has not been independently attested by a third party. Test-only mocks check call-shape/integration, not real dispatch; the production function has no transport injection. True model identity, authorized product prompt, 24 cohort cases, 12 exact frozen outbound requests, family isolation, provider billing, private freeze, independent reviewer and external witness require the genuine host execution path. No real model has been called by this PR.

Host-only original body/response bytes and credentials must remain outside Git. If a future P model returns multiple choices, partial JSON or markdown fences, do NOT repair it post hoc to score: fail closed, record blocked, obtain a new prospective approved study before rerun.
